# Experiment data

Written by `1D/scripts/run_experiment.py`. Each acquisition produces three files:

```
<experiment>_<agent>_<YYYYmmdd-HHMMSS>_timeseries.csv    one row per (trial, sample)
<experiment>_<agent>_<YYYYmmdd-HHMMSS>_trials.csv        one row per trial
<experiment>_<agent>_<YYYYmmdd-HHMMSS>_meta.json         config, protocol, column list
```

`--save-hidden` adds `..._hidden.pkl` with the GRU state, axes `(sample, layer, trial,
unit)` — a pickle rather than a CSV because it is not flat.

Nothing here is generated by training. These are test experiments on frozen agents.

## Loading

```python
import pandas as pd, json, glob

ts = pd.read_csv(sorted(glob.glob("data/preview_sweep_baseline_s1_*_timeseries.csv"))[-1])
tr = pd.read_csv(sorted(glob.glob("data/preview_sweep_baseline_s1_*_trials.csv"))[-1])
```

Both tables carry `netName` and `TN`, so they join on `TN` within one acquisition:

```python
df = ts.merge(tr[["TN", "T1_v_entry_out", "T1_peak_v_out"]], on="TN")
```

## Columns

**timeseries** — the movement itself, plus the trial's condition columns repeated down its
rows so it stands alone for grouping.

| column | meaning |
| ------ | ------- |
| `netName`, `TN`, `sample` | agent, trial number, sample index within the trial |
| `t_ms` | milliseconds from trial onset |
| `t_from_go_ms` | milliseconds from the go cue; negative during the hold, 0 at the cue |
| `x`, `v`, `a`, `u` | position, velocity, muscle activation, commanded force — signed, positive = rightward |
| `cur` | index of the target currently being pursued |
| `go` | has the go cue fired |
| `T1_now`, `T2_now`, `T3_now` | target positions **at this sample** (they move on jump trials); NaN for unused slots |
| design columns | `preview`, `n_targets`, `delay_steps`, `T1..T3`, plus whatever the experiment declared as factors |

**trials** — the design, the outcome, and per-target events.

| column | meaning |
| ------ | ------- |
| `success`, `timeout`, `false_start` | trial outcome |
| `wall_steps` | samples spent against the workspace boundary; should be 0 |
| `n_acquired` | how many targets were taken |
| `Tk_entry_sample` / `_ms` | first sample inside target *k*'s tolerance band — the pass-through moment |
| `Tk_acq_sample` / `_ms` | sample target *k* was registered as taken (differs from entry when a dwell is required) |
| `Tk_rt_ms` | entry time relative to the go cue |
| `Tk_v_entry`, `Tk_x_entry` | velocity and position at first entry |
| `Tk_v_acq`, `Tk_x_acq` | velocity and position at acquisition |
| `Tk_peak_v` | signed velocity of largest magnitude during the reach to target *k* |
| `fold` | `sign(T1)`, the direction-folding factor |
| `*_out` | the `*` column multiplied by `fold` |

## Two conventions that decide what the numbers mean

**Fold before pooling directions.** The learned policy is not mirror-symmetric — leftward
and rightward reaches leave T1 at different mean speeds. The `*_out` columns are already
multiplied by `sign(T1)`, so positive means "still travelling onward toward the next
target" in both directions. Regressing on unfolded, unpooled data picks up a
between-direction offset that has nothing to do with the next target.

**`d_next` is folded too**: positive means T2 lies beyond T1, onward from the start.

## Reproducing the co-articulation index

```python
from scipy import stats

s = tr[(tr.preview == 2) & tr.T1_v_entry_out.notna()]
dn = s.groupby("direction")["d_next"].transform(lambda z: z - z.mean())
vv = s.groupby("direction")["T1_v_entry_out"].transform(lambda z: z - z.mean())
print(stats.linregress(dn, vv).slope)
```

The demeaning within direction is the fixed-effects estimator described in §5.1 of the
doc. The same computation on `preview == 1` returns exactly 0 — with the next target
absent from the observation, a deterministic policy on a noiseless plant produces
bit-identical trajectories across every T2. That is the causal control, and a non-zero
value there means something is wrong with the pipeline.

## Provenance

`_meta.json` records the full agent config, the protocol (`noiseless`, `deterministic`,
`seed`), the experiment's parameters, the acquisition time, and the source run directory.
Deterministic protocols mean an acquisition can be reproduced exactly by re-running the
same command.
